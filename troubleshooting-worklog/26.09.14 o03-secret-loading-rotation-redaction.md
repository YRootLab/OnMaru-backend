# O03 server-only secret loading·rotation·redaction 작업 로그

## 날짜

2026-09-14

## 문제 상황

Issue #72는 TourAPI, Odii, Gemini, OAuth, OTLP secret을 browser와 repository에서 격리하고, 필수 secret 누락 시 안전하게 startup을 실패시키며, rotation overlap과 log redaction을 테스트로 고정하는 작업이었다.

## 오류명 또는 실패 증상

- `ModuleNotFoundError: No module named 'onmaru_ai.config'`: FastAPI secret 경계 테스트를 먼저 작성한 뒤 구현 전 RED에서 발생했다.
- Java `cannot find symbol`: Spring `SecretBundle`, `SecretProvider`, `SecretConfiguration`, `RedactingMessageConverter` 테스트가 구현 전 compile 단계에서 실패했다.
- 리뷰 지적: redaction utility만 있고 실제 logging output 경로에 연결되지 않아, application code가 secret을 log로 남기면 redaction이 보장되지 않았다.
- pytest collection 실패: FastAPI 기본 source를 `environment`로 fail-closed 변경한 뒤 전역 `app = create_app()`이 test import 시 실제 env secret을 요구했다.
- GitHub `closingIssuesReferences` 미표시: PR base가 default branch가 아니라 `develop`이라 `Closes #72`가 PR close reference로 자동 인식되지 않았다.

## 기존 구조나 방식의 한계

Spring과 FastAPI skeleton에는 health/readiness만 있었고 secret loading 경계가 없었다. 처음에는 redaction을 `SecretRedactor` utility 테스트로만 고정했지만, 운영 요구는 “값을 바꿀 수 있다”가 아니라 “log output 전에 current/previous secret이 사라진다”였기 때문에 실제 logging path wiring이 필요했다.

또한 fake provider를 기본값으로 두면 local test는 편하지만 production 설정 누락 시 deterministic fake secret으로 떠버릴 수 있었다. secret 정책 작업에서는 이 편의보다 fail-closed가 더 중요했다.

## 관련 코드 맥락

- `apps/spring-api/src/main/java/com/yrootlab/onmaru/config/secrets/SecretConfiguration`
  - 담당 로직: `onmaru.secrets.source` 설정을 읽어 `EnvironmentSecretProvider` 또는 `FakeSecretProvider`를 선택하고, `requiredNames`의 current secret을 startup 시점에 모두 조회한다.
  - 입력/출력: Spring configuration properties를 입력으로 받아 `SecretProvider`와 `SecretRedactor` bean을 만든다.
  - 핵심 분기: source가 `ENVIRONMENT`이면 `System.getenv()` 기반 provider를 쓰고, source가 `FAKE`이면 test/local용 deterministic provider를 쓴다.
  - 문제 연결: 기본값이 fake이면 설정 누락이 startup failure로 드러나지 않으므로, 기본값을 `ENVIRONMENT`로 바꾸고 테스트는 fake를 명시하도록 했다.

- `apps/spring-api/src/main/java/com/yrootlab/onmaru/config/secrets/RedactingMessageConverter`
  - 담당 로직: Logback `%redactedMsg` converter로 동작하며 `ILoggingEvent.getFormattedMessage()` 결과를 `SecretRedactor`에 통과시킨다.
  - 입력/출력: formatted log message를 입력받고 current/previous secret 값을 `<REDACTED>`로 치환한 문자열을 반환한다.
  - 문제 연결: 단순 utility만 있으면 실제 console appender가 redaction을 쓰지 않는다. `logback-spring.xml`에서 message pattern을 `%redactedMsg`로 바꿔 output 경로에 강제했다.

- `ai/src/onmaru_ai/config/secrets.py`
  - 담당 로직: FastAPI runtime의 `SecretProvider`, `SecretBundle`, `SecretRedactor`, `RedactingLogFilter`를 제공한다.
  - 입력/출력: `ONMARU_SECRETS_SOURCE`와 `ONMARU_SECRET_<NAME>_CURRENT/PREVIOUS` 환경 변수를 읽어 secret bundle을 만들고, logging record message를 redaction된 message로 갱신한다.
  - 핵심 분기: `provider_from_environment()`의 기본 source는 `environment`다. test는 `ai/tests/conftest.py`에서 fake source를 명시한다.
  - 문제 연결: fail-closed 기본값 때문에 import 시 전역 `app = create_app()`이 env secret을 요구했고, pytest에서는 fake source를 명시해 test bootstrap만 격리했다.

## 검토한 선택지

1. Redaction utility만 제공하고 각 logging call에서 수동으로 호출한다.
2. Spring/FastAPI logging framework에 redaction filter/converter를 연결한다.
3. Fake provider를 기본값으로 두고 production 배포 문서에서 override를 요구한다.
4. Environment provider를 기본값으로 두고 test/local에서 fake를 명시한다.
5. PR merge 전 Issue #72를 수동 close한다.

## 판단 기준

- secret 설정 누락은 조용히 성공하면 안 된다.
- current와 previous secret 모두 rotation overlap 동안 동일하게 검증·redaction되어야 한다.
- 테스트는 실제 output 경로를 보호해야지 helper 함수 존재만 확인하면 안 된다.
- GitHub Issue는 merge와 acceptance criteria 확인 전 닫지 않는다.

## 최종 결정

Environment provider를 기본값으로 두어 fail-closed로 동작하게 하고, test/local은 fake provider를 명시한다. Redaction은 utility가 아니라 Spring Logback converter와 Python logging filter에 연결한다.

## 해결 방식

- Spring에 `SecretBundle`, `SecretProvider`, `EnvironmentSecretProvider`, `FakeSecretProvider`, `SecretConfiguration`, `SecretRedactor`를 추가했다.
- Spring `OnMaruSecretProperties` 기본 source를 `ENVIRONMENT`로 두고, 기존 context/health tests는 `onmaru.secrets.source=fake`를 명시했다.
- Spring `logback-spring.xml`에서 console pattern의 message를 `%redactedMsg`로 바꾸고, `RedactingMessageConverter`가 installed `SecretRedactor`를 사용해 formatted message를 치환하게 했다.
- FastAPI에 `config/secrets.py`를 추가하고, `create_app()`에서 required secret validation과 logging redaction installation을 수행하게 했다.
- FastAPI test bootstrap은 `ai/tests/conftest.py`에서 `ONMARU_SECRETS_SOURCE=fake`를 기본 지정해 import-time app 생성과 fail-closed 정책을 양립시켰다.
- `.gitignore`는 nested `secrets/`, `credentials/` ignore를 유지하되 Spring source package `config/secrets`만 unignore했다.
- CI에 `uv run ruff check`와 `uv run mypy`를 추가했다.
- PR #151을 만들고 Issue #72에는 develop PR이라 auto-close reference가 안 잡힐 수 있음을 코멘트로 남겼다.
