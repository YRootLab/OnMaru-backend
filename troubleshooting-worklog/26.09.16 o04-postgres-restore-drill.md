# O04 PostgreSQL restore drill

## 문제

backup 성공 로그만으로는 새 database에 실제로 복원되는지, backup 이후 접수된 회원 삭제가 다시 노출되지 않는지, RPO 24시간과 RTO 4시간을 만족하는지 증명할 수 없었다. hosting provider가 정해지지 않아 WAL 기반 PITR 성공도 주장할 수 없는 상태였다.

## 구현

- `onmaru_backup` membership을 가진 non-superuser credential만 허용하는 PostgreSQL 17 backup runner를 추가했다.
- custom-format dump와 metadata·critical count를 임시 bundle로 만든 뒤 GPG AES-256으로 암호화하고 checksum과 7일 retention을 적용했다.
- restore runner가 checksum, 복호화, source/target fingerprint, 빈 target을 확인한 뒤 deletion ledger replay와 integrity suite를 한 번에 수행하도록 구성했다.
- evidence에는 connection string, secret, member ID를 넣지 않고 source revision, artifact digest, RPO/RTO와 aggregate count만 기록했다.
- provider PITR은 hosting, WAL retention, recovery ID가 확정될 때까지 `UNAVAILABLE_UNTIL_HOSTING_SELECTED`로 유지했다.

## 통합 drill에서 찾은 문제

1. PostGIS Alpine image가 ARM manifest를 제공하지 않아 local build가 시작되지 않았다. runner는 multi-arch `postgres:17-alpine`을 사용하고 database container만 `ONMARU_POSTGIS_PLATFORM` 기본값 `linux/amd64`로 실행하도록 분리했다.
2. `pg_isready`가 PostGIS entrypoint의 임시 server에도 성공해 migration 도중 connection이 종료됐다. init-complete log와 `PostGIS_Version()`을 모두 확인하도록 readiness gate를 강화했다.
3. SQL directory 전체에 `0444`를 적용해 traversal이 막혔다. file read와 directory execute를 함께 보장하는 `chmod -R a+rX`로 교정했다.
4. target DB에 미리 설치된 PostGIS schema가 dump의 extension restore와 충돌했다. target을 `template0`에서 다시 생성해 진짜 빈 database에 복원했다.
5. 초기 RTO 계산이 checksum과 복호화를 제외했다. 측정 시작점을 artifact verification 앞으로 옮겼다.
6. CI가 지정한 외부 evidence 경로를 restore container에 mount하지 않아 성공 JSON을 업로드할 수 없었다. 전용 `/evidence` bind mount와 계약 테스트를 추가했다.
7. 독립 review에서 dump와 critical count가 서로 다른 MVCC snapshot을 읽어 정상 운영 write에도 count mismatch가 날 수 있음을 찾았다. read-only transaction의 `pg_export_snapshot()`을 dump와 count query가 함께 사용하도록 교정했다.
8. empty guard가 `onmaru*` schema만 세어 `public` 등 다른 사용자 relation을 놓쳤다. system·temporary·extension-owned relation만 제외한 모든 user relation을 검사하고 실제 pre-existing table 거부 drill을 추가했다.
9. checksum sidecar가 임의 파일의 hash line도 검증할 수 있었다. sidecar 한 줄의 digest와 basename을 현재 artifact에 직접 결합하고 backup·ledger 모두 실제 digest를 다시 계산하도록 교정했다.
