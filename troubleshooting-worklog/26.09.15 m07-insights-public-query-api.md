# M07 관광 관측 공개 조회 API 작업 로그

날짜: 2026-09-15

## 문제 상황

#138은 방문자 관측과 관광지 집중률을 지도에 제공하되, 지연 관측을 실시간 혼잡도처럼 보이지 않게 하는 공개 조회 API 작업이었다. #90에서 만든 typed observation 모델을 기반으로 `basisDate`, `spatialLevel`, `unit`, `coverageStatus`를 응답까지 유지해야 했다.

## 오류명 또는 실패 증상

TDD 첫 실행은 `InsightsQueryService`, `ObservationPage`, `HeatmapResponse` 등 query 타입이 없어 compile RED가 났다. Spring boundary 테스트도 `/api/v1/insights/**` controller가 없어서 RED로 시작했다.

## 기존 구조나 방식의 한계

`modules:insights`에는 adapter용 observation 타입만 있고 공개 조회용 page/heatmap DTO와 query store가 없었다. 또한 기존 R2 `Observation` schema에는 `spatialLevel`이 빠져 있어 이슈의 acceptance criteria와 public serializer가 어긋났다.

## 관련 코드 맥락

- `modules/insights/src/main/java/com/yrootlab/onmaru/insights/query/InsightsQueryService.java`
  - `listObservations(regionCode, metric, from, to)`는 지역·metric·날짜 범위로 observation을 필터링한다.
  - `heatmap(regionCode, observedDate, metric)`은 해당 일자의 heat spot을 반환하고, 없는 경우 `coverageStatus: MISSING`, 빈 `spots`를 반환한다.
  - 결측 item이 있으면 aggregate coverage도 `MISSING`으로 내려서 0 합성을 피한다.

- `apps/spring-api/src/main/java/com/yrootlab/onmaru/web/insights/InsightsController.java`
  - `/api/v1/insights/observations`와 `/api/v1/insights/heatmap`을 제공한다.
  - 잘못된 날짜는 `VALIDATION_ERROR`와 field detail로 매핑한다.

- `docs/contracts/openapi/r2-map-audio-insights.openapi.yaml`
  - `Observation`에 `spatialLevel`을 required field로 추가해 구현과 계약을 맞췄다.

## 검토한 선택지

1. 기존 heatmap fixture shape만 맞추고 spatialLevel은 내부에만 둔다.
2. public Observation contract에 spatialLevel을 추가한다.
3. 결측 coverage를 HTTP 404/503으로 처리한다.
4. 결측 coverage를 200 + `MISSING` + 빈 배열 또는 nullable value로 반환한다.

## 판단 기준

- FE가 관측 단위와 결측 상태를 오해하지 않아야 한다.
- R2 fixture와 OpenAPI serializer가 실제 응답과 맞아야 한다.
- 관측 부재는 장애가 아니므로 안정적인 빈 응답이 필요하다.

## 최종 결정

공개 Observation에 `spatialLevel`을 포함하고, 결측·미관측은 `MISSING` 상태로 표현하는 query API를 구현했다.

## 해결 방식

- insights query DTO/store/service를 추가했다.
- Observation page와 heatmap response를 MockMvc로 검증했다.
- missing heatmap은 visitorCount 0이 아니라 빈 `spots`와 `coverageStatus: MISSING`으로 반환했다.
- R2 OpenAPI와 `insights-observations-normal` fixture에 `spatialLevel`을 반영했다.
