# AI02 FastAPI intake guardrail 작업 기록

## 날짜

2026-09-15

## 문제 상황

Issue #83은 모델 호출 전에 사용자 입력을 결정론적으로 허용·거절하는 FastAPI intake 정책을 구현하는 작업이다. HTML, prompt injection, 전화번호 같은 개인정보, 서비스 범위 밖 질문은 provider 호출 없이 거절되어야 하고, 정상적인 한국 지명과 한옥/시장/산책 요청은 후보 검색 단계로 넘어가야 했다.

## 오류명 또는 실패 증상

- RED 테스트에서 `ModuleNotFoundError: No module named 'onmaru_ai.intake'`가 발생했다.
- 구현 후 첫 GREEN 시도에서 `010-1234-5678로`처럼 한국어 조사가 붙은 전화번호가 `PRIVACY_REDACT_REQUIRED`가 아니라 `ASK_REGION`으로 판정됐다.

## 기존 구조나 방식의 한계

AI01로 내부 service token 경계는 생겼지만, FastAPI 내부에 provider 호출 전 정책 판정 패키지는 없었다. 따라서 향후 provider adapter가 붙으면 raw 입력이 scope/privacy/safety 판정 없이 모델 호출로 이어질 수 있었다.

## 관련 코드 맥락

- `ai/src/onmaru_ai/intake/policy.py`
  - `evaluate_intake(raw_query)`가 NFC normalize와 trim을 수행한다.
  - HTML/script 태그와 prompt injection 문구는 `SAFETY_BLOCKED`로 차단한다.
  - 전화번호/이메일은 `PRIVACY_REDACT_REQUIRED`로 차단한다.
  - 한옥/한옥카페/전통시장/산책 등 journey taxonomy가 없거나 시험/숙제/법률/의학 같은 범위 밖 요청은 `JOURNEY_SCOPE_UNSUPPORTED`로 돌린다.
  - theme은 있지만 지역이 없으면 `ASK_REGION`으로 반환해 provider 호출을 막는다.

- `ai/tests/intake/test_policy.py`
  - 정상 지명, HTML, prompt injection, PII, 범위 밖 질문, 지역 누락을 fixture matrix로 검증한다.
  - 모든 거절 경로에서 `should_call_provider == False`를 확인한다.

## 검토한 선택지

1. LLM/외부 moderation API로 safety와 scope를 판정한다.
2. FastAPI에서 작은 deterministic regex/rule matrix를 먼저 둔다.
3. Spring에만 policy를 두고 FastAPI는 trusted request만 받는다.
4. Pydantic/Guardrails류 외부 validator를 도입한다.

## 판단 기준

- 이 이슈의 acceptance는 provider 호출 0인 거절 경로다.
- 개인정보와 prompt injection은 모델 호출 전에 차단되어야 한다.
- 현재 범위는 완전한 moderation 제품이 아니라 MVP fixture matrix다.
- 향후 Spring policy와 FastAPI policy가 분리되더라도 FastAPI provider boundary 앞의 마지막 방어선이 필요하다.

## 최종 결정

외부 모델이나 새 라이브러리 없이 `onmaru_ai.intake` 패키지에 deterministic rule 기반 policy를 구현한다.

## 해결 방식

- 실패하는 pytest fixture matrix를 먼저 작성했다.
- `IntakeDecisionType`, `JourneyIntent`, `IntakeDecision`, `evaluate_intake()`를 추가했다.
- 개인정보 탐지 정규식은 단어 경계가 아니라 숫자 경계로 잡아 한국어 조사가 붙은 전화번호를 놓치지 않게 했다.
- provider 호출 여부는 `should_call_provider` boolean으로 명시했다.

## 결과

- 정상 입력 `전주 한옥마을에서 조용한 산책 코스 추천해줘`는 `SEARCH_CANDIDATES`와 region/theme/mood intent로 판정된다.
- HTML/prompt injection은 `SAFETY_BLOCKED`로 차단된다.
- 전화번호는 `PRIVACY_REDACT_REQUIRED`로 차단된다.
- 범위 밖 질문은 `JOURNEY_SCOPE_UNSUPPORTED`로 차단된다.
- 지역 없는 여정 요청은 `ASK_REGION`으로 멈추며 provider 호출을 하지 않는다.
- 검증:
  - `cd ai && uv run pytest tests/intake/test_policy.py -q`
  - `cd ai && uv run ruff check src/onmaru_ai/intake tests/intake && uv run mypy src/onmaru_ai/intake tests/intake`
  - `cd ai && uv run pytest`
