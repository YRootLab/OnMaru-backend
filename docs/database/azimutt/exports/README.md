# Azimutt exported images

이 디렉터리는 Azimutt에서 사람이 보기 좋게 배치한 뒤 export한 PNG/SVG 이미지를 둔다.

권장 파일명은 다음과 같다.

```text
onmaru-erd-system-overview.png
onmaru-erd-identity-auth.png
onmaru-erd-catalog-kto.png
onmaru-erd-discovery-journey.png
onmaru-erd-map-community.png
onmaru-erd-operations-sync.png
onmaru-erd-ai-rag.png
```

Azimutt project를 수정하거나 DBML schema를 바꾼 뒤에는 `docs/database/azimutt/onmaru-schema.azimutt-strict.sql`을 다시 import하고, 위 PNG들을 다시 export한다.
