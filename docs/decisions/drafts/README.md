# ADR Drafts

이 폴더는 정식 ADR을 만들기 전의 검토 자료다. 여기의 선택은 승인된 결정도, 구현 시작 신호도 아니다.

- [Foundation architecture](foundation-architecture.md): 모듈 경계, PostgreSQL 소유권, REST polling run lifecycle, dataset publication, optional RAG의 다섯 초안

정식 결정은 검토 후 `docs/decisions/`에 ADR로 기록한다. 승인 상태는 상위 [결정 목록](../README.md)에서만 확인한다.
