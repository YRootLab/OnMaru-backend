# #691 공공 촬영지 원천 기반 K-Contents 라벨링

## 적용 결과 (2026-10-12)

- 원천: [한국문화정보원_미디어콘텐츠 영상 촬영지 데이터](https://www.data.go.kr/data/15111405/fileData.do), CSV 15,034행. 다운로드 SHA-256 `1eba00010a3274e58a302d3dfdf0b7e56b4d7af3fe03680edfeae9866845ce3c`.
- 운영 활성 TourAPI 장소 23,598곳과 이름·주소·좌표를 대조했다. 넓은 자동 매칭은 후보 577관계이며 게시 대상이 아니다. 전통·역사 우선 분류 7,282곳에서 엄격한 이름·주소 일치와 거리 30m 이내 후보를 따로 검토했다.
- 장면 원문에서 해당 장소의 등장을 확인한 23개 작품·장소 관계를 14곳에 추가했다. 기존 3건을 합쳐 공개 관계 26건, 선별 공개 장소 17곳, 작품 26개다. 운영 `https://api.onmaru.site/api/v1/discovery/places?limit=20`에서 17곳, `/api/v1/k-contents/works?limit=20`에서 26개를 확인했다. `/api/v1/places/p-tourapi-252529/k-contents`에서 근거와 요약이 노출되는 것을 확인했다.
- 작품명·매체 유형은 CSV 필드로 확정했다. Codex가 작성한 관계별 한 문장 장면 요약은 CSV 장소설명과 대조하여 `VERIFIED`로 저장했다. 태그 23개는 `REVIEW_REQUIRED` 후보로만 저장했고 공개 태그는 없다. 작품 줄거리·장르·연도·배우 크레딧·이미지는 이 원천만으로 생성하지 않았다.
- `production-official-filming-reviewed.sql`과 `production-official-filming-selected.sql`은 각각 기본 `ROLLBACK`이며, 적용할 때만 `-v apply=1`을 사용한다. 재실행을 위한 migration이 아니라 2026-10-12 게시 기록이다. 새 원천 revision이나 주소·해시가 바뀌면 재검토한다.

## 14일 증분 라벨링 기준

1. TourAPI 활성 장소와 한국문화정보원 CSV를 각각 version/fingerprint로 보관한다. 주소·좌표가 달라진 장소는 이전 승인을 재사용하지 않는다.
2. 미디어타입 `drama`·`movie`만 먼저 사용한다. 이름·주소 정규화 일치, 좌표 30m 이내, 중복 후보 없음으로 좁힌다. 거리·지역 유사성만으로 촬영 관계를 만들지 않는다.
3. 원문 장면이 장소 자체를 나타내는지 확인한다. `앞`, `근처`, `맞은편`, `멀리`, 기록 영상, 단순 통과와 같은 서술은 별도 검토에 남긴다. 장소명이 같은 다른 지점도 수동으로 구분한다.
4. LLM은 근거가 통과한 관계의 **장면 요약**과 **관계 태그 후보**에만 호출한다. 원문 행 번호, 장소 ID, 원문 발췌, 원천 fingerprint를 함께 저장한다. 요약은 1문장, 500자 이하로 하고 원문에 없는 연도·인물·사건을 더하지 않는다. 태그는 `RELATION_CONTEXT` 후보로 보관한 뒤 통제 어휘·동의어·사람 검토를 거쳐 공개한다.
5. 장소 타입과 TourAPI taxonomy는 규칙으로 처리한다. 작품 줄거리·장르·테마·방영연도·크레딧은 이 CSV에 근거가 없으므로 비운다. 별도 공식 출처를 확보한 뒤에만 작품 요약/태그를 채운다. 포스터·스틸·배우 이미지도 별도 이용 권리 확인 전에는 비운다.
6. 14일마다 새 원천 행 또는 fingerprint 변경분만 처리한다. 동일 근거+프롬프트 버전의 결과는 재사용한다. 실패와 모호한 후보는 큐에 남기고 검증된 기존 게시본을 유지한다. LLM 호출 수, 후보 수, 검토·거절 수, 공개 수, 오매칭을 기록한다.
