# 릴리스 버전 결정 기록

릴리스 정책(`scripts/release/version-policy.mjs`)은 기본적으로 직전 태그의 다음 패치만 허용합니다. minor 또는 major 상승은 여기에 결정을 기록하고 `APPROVED_MINOR_RELEASES`에 추가한 뒤에만 허용합니다.

## v0.4.0 (minor, 승인: 2026-11-10)

- 범위: AI 여정 연동(#807~#811)과 여정 실행 DB 큐 전환(#821), 운영 Postgres pgvector 정렬(#827), 릴리스 v0.3.56(#828)까지의 `master` 내용.
- 근거: AI 연동 경로가 처음으로 기능 단위로 들어왔고, 공개 여정 단계 계약(6단계)과 DB 기반 실행 큐가 바뀌었습니다. 릴리스 프로세스상 Release Please가 `feat` 커밋을 근거로 minor를 제안했고, 운영 책임자가 이를 승인했습니다.
- 연관 AI 엔진: 같은 기간의 AI 엔진 릴리스 라인을 0.4.0과 맞춰 추적합니다. AI 엔진 이미지는 digest로 고정해서 배포합니다.
- 되돌리기: 태그 `v0.4.0`은 삭제하지 않습니다. 문제가 있으면 `v0.4.1` 패치로 수정합니다.
