# TourAPI 신분류체계와 관광타입 연계 정의서

> 원본: `신분류체계정보_관광타입정보_연계_정의서.xlsx`
> 이 문서는 원본의 분류·연계 행을 읽기 쉬운 계층 구조로 옮기고, OnMaru의 초기 적용 범위를 덧붙인 자료입니다. 원천 분류를 수정하거나 장소를 곧바로 “한옥”으로 단정하지 않습니다. 원천 코드와 OnMaru 주제 분류는 별도로 보존합니다.

- 소분류 행: **240개**
- 계층: 대분류 → 중분류 → 소분류
- 각 소분류의 `contentTypeId` 연계 포함

## OnMaru 적용 범위

OnMaru는 여행 코스를 짜 주는 서비스가 아니라 전통 건축·지역문화 장소와 그 장소에서의 경험을 소개합니다. 따라서 TourAPI의 모든 데이터를 공개 대상으로 삼지 않습니다. 중분류는 탐색 범위를 정하는 데 쓰고, 소분류와 장소별 관련성으로 공개 후보를 좁힙니다. 기존 장소 데이터는 이 정책에 맞지 않는다는 이유만으로 삭제하지 않으며, 원천 보관과 서비스 노출 판정을 분리합니다.

### 우선 포함 후보

| 신분류 중분류 | 포함할 소분류 | OnMaru에서의 의미 |
|---|---|---|
| `HS01 역사유적지` | 고궁, 성·산성·성곽, 문, 고택, 생가, 민속마을, 사적지, 사당, 근대건축물, 기타 역사유적지. 고분·능 및 선사유적지는 설명과 장소성이 확인되는 경우 포함 | 한옥에 한정하지 않고 궁궐·성곽 등 전통·역사 건축과 문화유산을 함께 소개 |
| `EX01 전통체험` | 전통문화체험 | 장소에 연결된 전통문화 경험 |

| `AC03 펜션/민박` | `AC030200 한옥스테이`만 | 일반 숙박업소 전체를 포함하지 않음 |

### 초기 공개 범위에서 제외

- `C01 추천코스`: 코스·여행 플랜 기능을 제공하지 않으므로 장소 카탈로그와 분리합니다.
- `EV 축제/공연/행사`: 기간·운영 상태가 수시로 바뀌므로 별도 수명주기를 설계하기 전에는 장소 카탈로그 공개 범위에 넣지 않습니다.
- 대부분의 `LS 레저스포츠`, 일반 숙박·쇼핑·음식점 등 주제와 직접 관련 없는 범용 분류.
- 장소 자체와 무관하게 단지 근처에 있다는 이유만으로 연결한 자연·관광 데이터.

위 표의 후보 범위는 원천 수집량을 제한하는 API 호출 조건과 같지 않습니다. 원천 레코드는 동기화해 보존할 수 있으며, 공개 후보 판정·작품 촬영지 라벨·소리마루 연결은 별도 기준과 증거를 통해 관리합니다. 특히 작품명·방송/발매 정보는 이 관광분류표에서 유추하지 않습니다.

- 왼쪽은 신분류 대·중·소분류 코드와 명칭입니다.
