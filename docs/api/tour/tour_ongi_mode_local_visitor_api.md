# Feature: 온기모드 (OnGi Mode) — 한국관광공사 빅데이터 기초지자체 방문자수 API

본 문서는 온마루의 '온기모드' 기능에서 **관광지 집중률 데이터와 함께 활용할 기초지자체 실제 방문자수 데이터**의 API 명세를 정리한 문서입니다.

> 💡 집중률(%) API가 "지금 해당 관광지가 얼마나 붐비는가"를 알려준다면, 이 API는 "실제로 몇 명이 기초지자체(시/군/구)에 방문했는가"를 알려줍니다.
> 두 데이터를 조합하면 유저에게 훨씬 세분화되고 직관적인 기초 단위 혼잡도 정보를 제공할 수 있습니다.

---

## 1. API 개요

| 항목 | 내용 |
|---|---|
| **서비스명** | 한국관광공사_빅데이터_지역별 방문자수 |
| **제공기관** | 한국관광공사 |
| **데이터 출처** | ㈜KT (내국인) · SK텔레콤(주) (외국인) 이동통신 데이터 기반 |
| **Base URL** | `http://apis.data.go.kr/B551011/DataLabService` |
| **데이터 성격** | 일상생활권(거주·통근·통학)을 벗어나 관광 등의 목적으로 일정 시간 머문 사람의 **일자별 기초지자체 순방문자 수** (추정치) |

---

## 2. 엔드포인트

### GET `/locgoRegnVisitrDDList` — 기초지자체 지역 방문자수 집계 데이터 조회

기초지자체(시/군/구) 단위의 일자별 방문자수 집계 데이터를 조회합니다.

---

## 3. 요청 파라미터 (Request Parameters)

| 파라미터 | 타입 | 필수 | 설명 | 예시 |
|---|---|---|---|---|
| `serviceKey` | string | ✅ | 공공데이터포털 인증키 | (발급받은 키) |
| `MobileOS` | string | ✅ | OS 구분 | `ETC` |
| `MobileApp` | string | ✅ | 서비스명 (앱 이름) | `OnMaru` |
| `startYmd` | string | ✅ | 조회 시작 일자 (YYYYMMDD) | `20260601` |
| `endYmd` | string | ✅ | 조회 종료 일자 (YYYYMMDD) | `20260625` |
| `signguCd` | string | | 기초지자체 시군구 코드 (미입력 시 전체 조회) | `11110` (종로구) |
| `numOfRows` | number | | 한 페이지당 결과 수 | `10` |
| `pageNo` | number | | 페이지 번호 | `1` |
| `_type` | string | | 응답 형식 | `json` |

## 5. 응답 필드 상세

### Header

| 필드명 | 타입 | 설명 | 예시 |
|---|---|---|---|
| `resultCode` | string | 응답 결과 코드 | `"0000"` (성공) |
| `resultMsg` | string | 응답 결과 메시지 | `"OK"` |

### Body

| 필드명 | 타입 | 설명 |
|---|---|---|
| `totalCount` | number | 전체 결과 건수 |
| `numOfRows` | number | 한 페이지당 결과 수 |
| `pageNo` | number | 현재 페이지 번호 |

### Body > Items > Item

| 필드명 | 타입 | 설명 | 예시 |
|---|---|---|---|
| `baseYmd` | string | 기준 일자 (YYYYMMDD) | `"20260624"` |
| `signguCode` | string | 기초지자체 코드 (시군구) | `"11110"` |
| `signguNm` | string | 기초지자체명 (시군구) | `"종로구"` |
| `daywkDivCd` | string | 요일 구분 코드 (1:월 ~ 7:일) | `"3"` (수요일) |
| `daywkDivNm` | string | 요일 구분명 | `"수요일"` |
| `touDivCd` | string | 관광 구분 코드 | `"1"` (현지인), `"2"` (외지인), `"3"` (외국인) |
| `touDivNm` | string | 관광 구분명 | `"외지인"` |
| `touNum` | string | 방문자 수 (순방문자 기준) | `"54321"` |

## 6. 데이터 활용 시 유의사항

### ⚠️ 반드시 인지해야 할 사항

1. **방문자 ≠ 관광객**: 이동통신 데이터 기반 추정치이므로, 단순 통근/통학/이동 인원도 일부 포함될 수 있어 관광지 실제 입장객과는 차이가 있을 수 있습니다.
2. **순방문자 집계**: 일자별 순방문자 기준이므로 한 명이 하루 동안 동일 기초지자체 내 여러 곳을 다녀도 1명으로 집계됩니다.
3. **광역 데이터와의 비교**: 기초지자체(`signguCode`)와 광역지자체(`areaCode`) 데이터는 집계 체계가 다르므로 단순 합산 또는 단순 비교 시 오차가 발생할 수 있습니다.
4. **데이터 지연**: 공공데이터포털 정책 및 가공 프로세스에 따라 실시간 조회가 아닌 과거 며칠 전까지의 집계 데이터로 제공됩니다.

## 7. 온기모드에서의 활용 방안

### 집중률 API + 기초지자체 방문자수 API 조합

| 데이터 | 출처 | 역할 |
|---|---|---|
| 집중률 (%) | `tatsCnctrRatedList` | 관광지 단위 혼잡도 → **"해당 관광지가 지금 얼마나 붐비나?"** |
| 기초지자체 방문자 수 (명) | `locgoRegnVisitrDDList` | 지자체 단위 방문자 추이 → **"이 동네 전체에 평소 얼마나 많이 오나?"** |

### 예상 UI 활용 예시

```
🏛️ 서울특별시 종로구 (경복궁 주변)
├── 오늘 집중률: 80% (혼잡)
├── 기초지자체 일일 방문자: 약 54,321명
├── 📊 "수요일에 비해 토요일에 방문객이 30% 증가합니다" (daywkDivNm 비교 활용)
└── 📈 최근 7일 종로구 전체 방문자 추이 그래프
```
