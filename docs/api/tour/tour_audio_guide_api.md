# 한국관광공사 관광지 오디오 가이드 (Odii) API 명세서

본 문서는 온마루 프로젝트의 **Feature 3: 온마루 오디(Odii) 도슨트** 기능에서 사용하는 한국관광공사 관광지 오디오 가이드 관련 API의 명세서입니다.

---

## 📋 공통 응답 필드 정의

조회되는 아이템(`item`) 객체 내의 주요 필드 설명입니다.

| 필드명 | 타입 | 설명 |
| :--- | :--- | :--- |
| `tid` | String | 관광지 ID |
| `tlid` | String | 관광지 언어 ID |
| `stid` | String | 이야기 ID |
| `stlid` | String | 이야기 언어 ID |
| `title` | String | 콘텐츠 제목 (예: 장소명 및 위치) |
| `mapX` | String | 경도 (X 좌표) |
| `mapY` | String | 위도 (Y 좌표) |
| `audioTitle` | String | 오디오 제목 (가이드 이름) |
| `script` | String | 오디오 도슨트의 전체 대본/자막 텍스트 |
| `playTime` | String | 오디오 재생 시간 (초 단위) |
| `audioUrl` | String | 오디오 스트리밍/다운로드 URL |
| `langCode` | String | 언어 코드 (예: `ko` 한국어) |
| `imageUrl` | String | 대표 이미지 URL |
| `createdtime` | String | 데이터 생성일시 |
| `modifiedtime` | String | 데이터 수정일시 |
| `syncStatus` | String | 동기화 상태 코드 (`A`: 추가, `U`: 수정, `D`: 삭제 - Sync API 전용) |

---

## 📋 관광지 공통 응답 필드 정의

조회되는 관광지 아이템(`item`) 객체 내의 주요 필드 설명입니다.

| 필드명 | 타입 | 설명 |
| :--- | :--- | :--- |
| `tid` | String | 관광지 ID |
| `tlid` | String | 관광지 언어 ID |
| `themeCategory` | String | 테마 카테고리 |
| `addr1` | String | 주소 1 (시/도) |
| `addr2` | String | 주소 2 (시/군/구) |
| `title` | String | 관광지명 |
| `mapX` | String | 경도 (X 좌표) |
| `mapY` | String | 위도 (Y 좌표) |
| `langCheck` | String | 언어 제공 여부 체크 |
| `langCode` | String | 언어 코드 (예: `ko` 한국어) |
| `imageUrl` | String | 대표 이미지 URL |
| `createdtime` | String | 데이터 생성일시 |
| `modifiedtime` | String | 데이터 수정일시 |
| `syncStatus` | String | 동기화 상태 코드 (`A`: 추가, `U`: 수정, `D`: 삭제 - Sync API 전용) |

---

## 📡 API 엔드포인트 명세

### 1️⃣ 이야기 기본 정보 목록 조회
*   **Endpoint**: `GET /storyBasedList`
*   **설명**: 특정 관광지 ID를 기준으로 등록된 이야기의 기본 정보를 조회합니다.
*   **주요 요청 파라미터**:
    *   `tid` (관광지 아이디)
    *   `tlid` (관광지 언어 아이디)
